> ⚠️ **Важно!** Это первая версия лаунчера, поэтому ожидайте множество багов.
> На данный момент не поддерживается игра на публичных серверах, а также интеграция с Forge.
> Прошу отнестись с пониманием, ведь этот лаунчер делают один разработчик и Claude. В скором времени лаунчер будет полностью переписан.

> 💡 **Хорошая новость:** Несмотря на то, что игра на публичных серверах пока недоступна, вы без проблем можете играть с друзьями по **локальной сети (LAN)**! Просто создайте мир и откройте его для сети.

## ✨ Возможности

- **Сборки.** У каждой свои версия, загрузчик, моды, миры, объём ОЗУ, JVM-аргументы и размер окна. Сборку можно сразу запускать с автовходом на сервер.
- **Моды, ресурспаки и шейдеры в один клик.** Поиск по каталогу [Modrinth](https://modrinth.com) прямо в лаунчере, нужные зависимости (например, Fabric API) ставятся сами. Свои `.jar` и `.zip` тоже можно добавить.
- **Модпаки.** Готовые сборки с Modrinth ставятся как новая сборка одним кликом. Есть импорт файлов `.mrpack`.
- **Fabric и Quilt.** Загрузчик выбирается при создании сборки.
- **Скины без ресурспаков.** Загрузили PNG (или взяли скин по нику), и он сразу в игре.
- **Любая версия.** От 1.7 до самых новых, включая снапшоты. Нужная Java скачивается автоматически.
- **Темы и персонализация.** 8 готовых тем, свой цвет акцента и выбор шрифта. Всё применяется без перезапуска.
- **Бэкап миров** одной кнопкой.
- **Счётчик времени в игре** для каждой сборки.

## 🚀 Как установить

1. Откройте раздел **[Releases](../../releases)** и скачайте файл **`Seed Launcher.exe`**.
2. Запустите его. Устанавливать ничего не нужно: Java и файлы игры лаунчер скачает сам при первом запуске.

> Windows или антивирус могут ругаться на неподписанный `.exe`. Это обычное дело для программ, собранных через PyInstaller. Исходный код открыт, так что вы можете проверить его или собрать лаунчер сами.

## 🎮 Игра с друзьями по сети

1. Оба игрока запускают **одну и ту же версию** (и одинаковые моды, если они есть).
2. Хост открывает мир, нажимает `Esc` → **Открыть для сети**.
3. Друг заходит в **Сетевая игра → Прямое подключение** и вводит IP хоста и порт из чата.

Если друзья находятся не в одной сети, подойдёт любой виртуальный LAN, например Radmin VPN. Не забудьте разрешить Java в брандмауэре Windows.

## 🛠 Запуск из исходников

Нужен только Python 3.9+, больше ничего ставить не требуется.

```bash
python seed_launcher.py
```

### Сборка `.exe`

Положите `seed_launcher.py`, `seed.ico` и `icon.png` рядом с `build.bat` и запустите его. Готовый файл появится в `dist/Seed Launcher.exe`.

Данные лаунчера хранятся в `%APPDATA%\.seedlauncher`.
