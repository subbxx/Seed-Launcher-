# Seed-Launcher-
быстрый и удобный лаунчер для майнкрафта( Java edition )
это первая версия лаунчера, ожидайте множество багов.
пока что не поддерживает игру на публичных серверах, а так же
не поддерживает Forge. прошу простить, ведь этот лаунчер
делает один разработчик и Claude, но в скором времени 
лаунчер будет полностью переписан.

Как установить
скачать Seed Launcher.exe и запустите, все зависимости установится сами
если вас интересно или если бы багхантер, то найти код проекта вы можете
в этом репозитории. если вы нашли баг, просьба сообщить о нем незамедлительно.

О главном
весь проект Seed Launcher - абсолютно бесплатный, мы придерживаемся этой
политики и будем придерживаться все время разработки

поставьте звезду если вам нравится наш проект!
